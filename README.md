# 견적온 (가칭) — 견적관리 시스템 시안

견적 작성부터 견적서 생성, 메일 발송, 주문 전환, 재고·출고·회수까지 한 흐름으로 이어지는 내부 업무 시스템의 작동 시안.
서버 없이 브라우저만으로 동작하며, 고객·품목·금액은 모두 예시 데이터다. 메일은 실제로 발송되지 않는다.

제안 평가용 시안이며 포트폴리오로 쓰지 않는다.

## 들어 있는 것

| 화면 | 내용 |
|---|---|
| 대시보드 | 상태별 견적 수, 미수금, 출고·회수 일정, 수량 부족·메일 실패 알림 |
| 견적 | 목록·검색·상태 필터, 품목·단가·수량·할인 입력, 기간 내 가용수량 표시와 부족 경고 |
| 견적 버전 | 확정·발송된 견적을 고치면 새 버전 생성, 이전 버전의 품목·단가·기간 보존, 변경 이력 |
| 견적서 | 지정 양식에 자동 채움, 한글 금액, 직인 자리, 인쇄·PDF 저장 |
| 메일 발송 | 수신자·제목·본문·첨부 자동 구성, 담당자 확인 후 발송, 실패·재시도, 중복 발송 방지, 발송 이력 |
| 주문·입금 | 견적 확정 후 주문 전환(재고 예약), 입금 상태, 예약 → 출고 → 회수 → 완료 |
| 재고·일정 | 품목별·날짜별 가용수량 표, 예약·출고 중인 주문 |
| 고객, 품목·단가 | 등록·수정, 입력값 검증 |
| 권한·백업 | 역할별 화면 제한(관리자·영업·물류), 백업 파일 내려받기·복구, 작업 기록 |

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 금액·기간·가용수량·중복 발송 판정 테스트
npm run build    # dist/ 생성
```

## 구조

- `src/lib/calc.ts` 금액, 대여 일수, 기간별 가용수량, 중복 발송 판정 (순수 함수, 테스트 대상)
- `src/store.ts` 상태 + localStorage (`quote-desk-demo`), 예시 데이터, 견적·메일·주문 동작
- `src/pages/` 화면, `src/components/ui.tsx` 공통 UI
- `scripts/serve.py <포트>` `dist/` 정적 서버

## 시안과 실제 구축의 차이

- 메일은 발송 과정만 흉내 낸다. 실제로는 Gmail 계정 인증 후 서버에서 보낸다.
- PDF 는 브라우저 인쇄 기능으로 만든다. 실제로는 서버에서 파일로 만들어 메일에 첨부하고 보관한다.
- 데이터는 이 브라우저에만 저장된다. 실제로는 기존 시스템의 DB 를 쓴다.
- 권한은 화면 전환으로만 보여 준다. 실제로는 로그인과 서버 쪽 검사가 들어간다.
- 업종(행사용품 대여)과 견적서 양식은 가정이다. 기존 시스템 분석 뒤 실제 양식·품목으로 바꾼다.
